# 坦克大战 3D · 街机 PvE Roguelite 改造设计总览

版本：v1.0（2026-11）
适用范围：`d:\IdeaProjects\tank-game`（Godot 4.7 + GDScript）

---

## 1. 为什么改

现状是一个"8 关一次性通关"的 PvE 游戏：关卡固定、数值固定、打通即结束，玩家没有第二次打开的理由。
目标是把已有的战斗系统（车体/炮塔分离操控、装甲分区、AP/HE、可破坏掩体、A\* AI、局域网合作）
装进一个 **Roguelite 外壳**，让每一局都不完全一样，并且局外有可持续的成长。

选择这条路线的原因：

- 战斗手感、AI、地形破坏已经达标，重写成本高、收益低；
- Roguelite 的留存来自"局内组合 × 局外解锁"，不依赖海量美术资产；
- 现有 9 种补给、5 台战车、10 项战绩统计可以直接变成卡池、起始套件与元数据；
- 局域网合作可以共享同一套 Run 状态，不需要重做联机架构。

---

## 2. 目标玩家体验

一局（Run）的节奏必须是：

1. **开局 30 秒内做出第一个有意义的选择**（选车 + 选挑战）。
2. **每 2~3 分钟拿到一张新卡**，每隔几分钟就能感到"这局变强了、打法变了"。
3. **每个战区末尾打一场硬仗**（Boss），形成节拍。
4. **失败不沮丧**：失败也把战功换成长期货币，下一次开局更强。
5. **单局 20~25 分钟**，可随时暂停退出（退出按失败结算）。

设计支柱（所有后续功能的取舍依据）：

| 支柱 | 含义 | 反例 |
| --- | --- | --- |
| 战斗优先 | 一切成长最终都体现在"怎么打"上 | 纯数值堆叠、无关小游戏 |
| 选择有代价 | 每张卡都有明确的得失 | 无条件正收益卡 |
| 读得懂 | 效果能从 HUD、音效、画面直接读懂 | 隐藏概率、看不见的加成 |
| 失败也有收获 | 战功必定转化 | 空手而归 |
| 合作共享 | 2~4 人共享同一局与同一份成长 | 各自独立跑一局 |

## 3. 本版本范围

### 3.1 本版本实现（代码可交付、可验收）

| 模块 | 内容 |
| --- | --- |
| 局结构 | 3 战区 × 3 关 = 9 关；关卡类型为 歼灭 / 坚守 / 决战（Boss）；每关结束三选一强化 |
| 卡牌 | 30 张卡、3 档稀有度、叠加上限、重掷、跳过补偿、稀有度保底 |
| 经济 | 局内战功、关卡奖励、击杀奖励、补给站（每战区末尾）、重掷与跳过价格 |
| 元进度 | 长期战功、战车解锁、3 项永久升级，写入 `user://meta.cfg` |
| 挑战 | 标准行动 / 每日挑战（日期种子）/ 精英行动（敌人带词缀），以及 6 个 Run 级修正 |
| 敌人词缀 | 5 种词缀（重甲 / 狂热 / 易爆 / 护盾 / 神射），按关卡概率附加 |
| 战斗规则 | 跳弹改为**按入射角的确定性阈值**，卡牌可降低阈值 |
| 表现 | 战功/卡牌/关卡类型 HUD 条、目标提示、卡牌与补给站界面 |
| 联机 | 房主权威的 Run 状态，客户端跟随显示；卡牌选择由房主统一结算 |

### 3.2 明确不在本版本内（需要外部资产或服务）

| 项 | 原因 | 后续阶段 |
| --- | --- | --- |
| 新模型 / 地形高度图 | 需要 Blender 资产与美术方向 | 阶段 D |
| 真实录音音效、背景音乐 | 需要音频资产授权 | 阶段 D |
| 多语言（中英） | 需要全量文案提取与翻译 | 发行前 |
| 内置字体 | 需要商用授权字体文件 | 发行前 |
| Steam 接入、成就、云存档 | 需要 Steamworks 账号与打包流程 | 发行阶段 |
| 改键界面 | 输入层已支持重建动作，缺 UI | 发行前 |
| 每名玩家独立卡池 | 会增加同步复杂度，先做共享卡池 | v2 |
| 手工设计地图 | 程序化地图先满足随机性 | 阶段 D |

范围边界的原则：**能在仓库内用代码与现有资产完成、能被无头探针验证的，才算本版本。**
本文档不把"换美术"写成已完成项。

## 5. 术语表

| 术语 | 含义 |
| --- | --- |
| Run / 一局 | 从按下出击到胜利或失败的一次完整流程 |
| 战区 / Zone | 3 关为一组，末尾有 Boss 与补给站 |
| 战功 / Credits | 局内货币，关卡与击杀获得，补给站消耗 |
| 补给券 / Meta Credits | 长期货币，结算时由战功转化 |
| 卡牌 / Card | 局内永久强化，可叠加到上限 |
| 词缀 / Affix | 附加在单个敌人身上的强化标签 |
| 修正 / Mutator | 作用于整局的全局规则改动 |
| 境界 / Stage Kind | 歼灭、坚守、决战三种关卡目标 |
